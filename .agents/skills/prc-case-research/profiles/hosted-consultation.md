# Hosted Consultation Context

Use only when a legal-consultation host explicitly invokes case research or the active project/task is clearly that consultation. Existing similarly named folders alone do not select this profile. The shared research and output standards apply unchanged.

## Input and scope

Reuse the host's decision questions, matter-wide dependency map, facts/evidence status, current-law findings, dates/locations, selected source, request scope and any limits actually set by the user. Do not restart intake or obtain a second confirmation for an already authorized matter.

The host owns the decision to enter database verification. After that choice, extend retrieval dynamically within scope whenever the research purpose remains insufficiently answered. No default case targets, return-batch ranges, POINT allowance, spending tiers or routine pricing/approval checkpoints apply. Single-use quality means adequately answering all controlling issues, not consuming a predetermined quantity.

Before transfer, the host may organize its existing matter plan. Save a separate `003_案件梳理与案例检索建议.md` only when it is useful or the host already uses it; otherwise the research record carries scope and dependencies.

## Files

- Host result: `004_给你的结果/001_咨询结果.md`; return findings for integration, never create a competing standalone report.
- Research record: `003_内部工作区/004_法律与案例检索记录.md`.
- Required retained judgments: `004_给你的结果/004_案例全文/` for every closely read or judgment-cited case.
- The record's case ledger doubles as the index. A separate `000_案例全文索引.md` is optional for larger/shareable collections or an existing host workflow. Preserve and update an existing index rather than breaking prior links.

Use `../references/output-schema.md` as the sole evidence/retention contract and its templates for the record and full texts. Keep online URLs in judgment provenance; user-facing judgment citations link to the local files. Include those files when distributing the report.

## Handoff

Return the qualified answer, decisive verified cases and local links, similarities and differences, strongest adverse path, evidence gaps, completed/missing coverage, current-law questions and operational limits. Integrate into the same host result without duplicating long analysis in the record.

Public cases used during intake are seeds until identity, original text, comparability, law version and material later treatment are checked. Keep a downgraded public lead and its explanation visible rather than silently erasing it. Public-source context must not be presented as completed database/full-text verification.

On confirmed credit exhaustion or insufficient remaining credits, stop further retrieval, save the current result, required texts and record, explain the specific limit and unfinished questions, and ask the user how to continue. The host relays that question; no second independent case-skill prompt is needed. Do not call the matter complete or silently switch source/quality level.
