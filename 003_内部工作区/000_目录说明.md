# 内部工作区

Agent 在这里保存咨询过程中生成的内部文件：案件状态、事实证据账本、材料处理副本、访谈记录、能力检查、问题地图和检索记录。它们用于继续工作和支持最终结果；用户通常无需整理或维护。

固定文件名：

- `001_案件工作底稿.md`
- `002_能力检查.md`
- `003_案件梳理与案例检索建议.md`
- `004_法律与案例检索记录.md`
- `010_材料处理/`：可检索副本、访谈记录和材料清单

案例核查取得的裁判全文不塞进内部底稿，统一保存到用户可核查的 `../004_给你的结果/004_案例全文/`；底稿和咨询结果使用相对链接引用。

内部文件不是原始证据，不得覆盖、移动或改名 `../002_你的材料/` 中的用户文件。用户可以查看和纠正；重大纠错应记录来源、时间和影响。

`002_能力检查.md` 只在用户选择深入核查后记录元典法规/案例 MCP 在 Codex 内的真实调用结果，不记录 Key。基础梳理不需要该检查；配置改变后深入核查前必须重测。
