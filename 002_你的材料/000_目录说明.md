# 你的材料

把文件直接放在当前 `002_你的材料/` 目录即可，不需要进入其他子目录，也不需要自己分类或改名。可能有利、不利、重复、矛盾或不确定的内容都可以保留。

Agent 登记材料时让原文件留在原处，保留原文件名和原始内容，不覆盖、裁剪、移动或格式转换。登记状态、SHA-256 和处理关系写入 `../003_内部工作区/010_材料处理/003_材料清单/`；OCR、转写、脱敏和其他处理副本写入 `../003_内部工作区/010_材料处理/001_可检索副本/`。

因此，在文件管理器中可以直接理解为：`002_你的材料` 是你放进来的内容，`003_内部工作区` 是 Agent 工作时生成的内容，`004_给你的结果` 是给你阅读或交付的内容。

不要把含真实案件材料的目录提交到 GitHub。`.gitignore` 只保留空目录说明。
